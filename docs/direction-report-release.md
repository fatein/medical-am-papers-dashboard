# Research-direction report release — 2026-11-03

The dashboard includes 35 direction reports in Chinese, English and German. Each direction has a report link in the summary table and a button beside its selected heading. Reader pages retain detailed branching and feedback diagrams, node interpretations and clickable sources.

The language versions cover 113 research questions, 318 diagram nodes and 442 source records (351 distinct source URLs). Company names, original paper titles and original reference records are retained. English and German are pre-generated static content, so opening a report does not submit visitor data or call translation services.

Translation review compared titles, questions, diagram nodes, section text, tables and edge labels against the Chinese source. It addressed terminology, study design and stage, material/drug identities, statistics, outcome direction, negation and distinctions between demonstrated results and future scenarios. Context-specific distinctions include mass versus quality, tissue versus organization, device clearance versus approval, disinfection versus sterilization, and sample recovery versus recycling.

Terminology sources consulted during review include [DIN Media’s additive-manufacturing terminology](https://www.dinmedia.de/de/themenseiten/additive-fertigungsverfahren), the [FDA’s 510(k) clearance explanation](https://www.fda.gov/medical-devices/device-approvals-and-clearances/510k-clearances), and the [EMA’s pharmaceutical-quality questions and answers](https://www.ema.europa.eu/en/human-regulatory-overview/research-development/scientific-guidelines/quality-medicines-questions-answers-introduction/quality-medicines-questions-answers-part-1).

Automated checks cover all 105 report variants, structural parity, citation preservation, reference equality, unresolved translation markers and untranslated Chinese outside preserved original references. Navigation checks cover opening a report, changing language and returning to the same research question and paper page.
