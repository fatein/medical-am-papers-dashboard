# 医疗增材制造论文 Dashboard（公开版）

本网站使用 Streamlit + Plotly，开放源码、只读访问。页面包含论文总览、研究结构与趋势、论文检索。详情页提供各分类维度的核验记录、证据节选及出处位置。公开包不包含完整摘要、长段原文、原始文件路径或本地导入功能。

当前收录 7,288 篇：2010–2025 年 6,092 篇，2026 年目前 1,196 篇（其中 1,077 篇建议纳入文献计量）。2026 年尚未结束，不应将其与完整年度直接比较。收录数反映本研究项目语料，不代表全领域论文总数。

2026 年的分类沿用来源工作簿已有的自动核验，并检查各标签的核验状态与证据片段是否一致；不要求访客逐篇人工复核。内容依据范围为原文片段 390 篇、摘要／元数据 776 篇、仅题名／元数据 30 篇。没有足够信息的工艺、材料仍标为“未确认”，内容依据范围不等于全文均已获取。

## 部署

在 Streamlit Community Cloud 中连接本公开仓库，入口文件选择 `public_app.py`。平台安装 `requirements.txt` 中的依赖并提供公开网址。这个部署包由本地完整项目的 `scripts/build_public_site.py` 生成；需要更新论文时，先在本地导入并验证，再重新生成、审查和提交公开包。
