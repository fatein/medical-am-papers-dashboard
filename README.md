# 医疗增材制造论文 Dashboard（公开版）

本网站使用 Streamlit + Plotly，开放源码。右上角可切换中文、英文和德文；公司名称、论文题名与论文原文保持原样。页面包含论文总览、研究结构与趋势、论文检索、学术与企业联系，以及企业格局、技术路线图、企业检索和反馈汇总。论文详情支持对 P、D、T、M 分类提出建议；反馈单独保存，不直接修改论文。公开包不包含完整摘要、长段原文、原始文件路径或本地导入功能。

当前展示 7,169 篇：2010–2025 年 6,092 篇，2026 年目前 1,077 篇。2026 年数据来自已完成的主题筛查与核心文献计量筛选；原始汇总表保留在本地，不随网站发布。2026 年尚未结束，不应将其与完整年度直接比较。收录数反映本研究项目语料，不代表全领域论文总数。

2026 年论文的医疗对象、疾病、工艺和材料证据分别从题名、摘要或可提取的 PDF 正文定位。找不到支持标签的文字时会显示 `insufficient evidence`，不会用通用题摘段落填充。

来源工作簿包含 347 条企业记录；合并 3 组重复主体后为 344 家。交叉分析资料中的 Triastek 与原库 Triastek, Inc. 为同一主体，去重后再加入 8 家新企业，现为 352 家。每家企业在技术地图中均有当前产品／技术现状位置。年度变化图仅计有来源的年度事件；新增企业的现状未作为发布日期。交叉分析按照 35 个方向、113 个问题组织论文、企业技术证据与专利法规路径。每个研究问题均提供独立分析报告，包含学术研究链路、企业演进、交叉分析、发展展望及可点击来源。企业库的分布及节点数量不等于全球市场规模、收入或份额。

## 专利模块

“专利检索”收录 5,516 条严格筛选的医疗增材制造直接相关公开记录，涉及 4,862 个已知同族组。支持医疗应用、原始申请人和公开年份的组合筛选、关键词检索及分页浏览。医疗应用可多标签匹配，申请人名称按原文精确匹配；年份为公开年份。同族内不同公开号仍分别展示，数量不代表独立发明数或全领域总量。

表格和详情中的“查看专利原文”链接按对应公开号打开 Espacenet。公开快照仅含必要书目信息、医疗应用标签及简短摘要节选，不包含专利全文、OPS 凭据或本机源文件。中英德界面均保留原始题名与申请人名称。

## 论文—专利—企业联动

联动页支持医疗应用、细分主题和报告范围筛选，在论文、专利和企业三个标签页查看详情及原文来源。

专利检索页增加公开年份趋势、医疗应用分布、申请人排行和公开地区分布，随当前筛选同步更新。

“医疗应用联动”共享医疗应用、细分技术主题与报告范围筛选，在三个标签页同步查看现有 7,169 篇论文、5,516 条严格专利公开记录和 352 份企业档案。细分主题来自明确对象词和上下文；没有细分主题证据的记录仍保留在医疗应用层浏览，不强行建立一一关系。申请人名称与企业名称的规范化精确对应单独展示，主题相似不会被解释为权属、合作、许可或产品实施。

35 份研究方向报告的“学术与企业联系”“转化关键问题与验证方法”“2027—2029 年条件、情景与观察指标”三部分，围绕具体专利方案重写。正文逐项连接论文发现、专利中的材料／结构／工艺变量、企业产品或制造环节、验证对照与年度观察指标；引用可直接打开论文、专利和企业来源。中文、英文和德文版本同步提供。

113 份研究问题报告与方向报告保留“专利证据与论文—企业串联”资料，支持打开对应范围的完整联动结果。完整研究方向报告可通过 `scripts/export_direction_reports.py --output <目录>` 导出为带来源链接的三语 HTML。

关联快照采用可复现的规则筛选，并校验来源文件哈希、实体 ID 与引用关系。它基于已持有的题名和摘要，不包含专利全文或权利要求分析，也不确认授权状态或临床优效。专利公开条数、已知同族数、论文数和企业数分别统计；同一记录可能与多份报告关联。

## 部署

在 Streamlit Community Cloud 中连接本公开仓库，入口文件选择 `public_app.py`。平台安装 `requirements.txt` 中的依赖并提供公开网址。这个部署包由本地完整项目的 `scripts/build_public_site.py` 生成；需要更新论文时，先在本地导入并验证，再重新生成、审查和提交公开包。

反馈保存至 GitHub Issues；访客在网站内操作，无需 GitHub 登录。在 Streamlit App settings → Secrets 中设置：

```toml
[feedback]
repository = "fatein/medical-am-papers-dashboard"
token = "替换为仅有此仓库 Issues 读写权限的专用凭据"
```

凭据仅保存在 Streamlit Secrets，不提交到仓库。公开模式缺少凭据时保留反馈查看入口，暂停提交，不将反馈保存到云端临时磁盘。反馈汇总向所有访客公开；关闭对应 Issue 后显示为已处理。论文分类反馈和分析报告评估分别归类，后者预留后续评估入口。
